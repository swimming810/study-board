# 课间 · 学习任务看板

一个使用 Vibe Coding（AI 辅助编程）开发的轻量级前端项目，用于管理学习任务、查看截止日期和统计完成进度，可作为课程实践项目。

## 运行方式

下载仓库后，直接双击 `index.html`，使用现代浏览器打开即可，无需安装依赖。

也可在项目目录运行 `python -m http.server 8000`，然后访问 http://localhost:8000 。推荐使用固定地址访问，便于浏览器持续保存数据。

## 功能

- 添加任务，设置截止日期与优先级。
- 勾选完成或恢复为待完成，删除时二次确认。
- 按全部、待完成、已完成筛选，并搜索任务名称。
- 自动统计任务数量、已完成数量和完成率。
- 自动按完成状态、截止日期排序，标记逾期任务。
- 通过 localStorage 保存数据，刷新页面后恢复。
- 适配电脑和手机屏幕。

## 设计思路

围绕“记录目标—跟踪进度—完成复盘”的学习流程，使用简洁的卡片布局呈现任务和统计信息。采用原生 HTML、CSS 和 JavaScript，避免依赖和构建步骤，让项目易于运行和理解。

任务由唯一 ID、名称、截止日期、优先级和完成状态组成。用户操作修改内存中的任务数组，再写入 localStorage 并重新渲染页面。任务名称通过 textContent 显示，避免把用户输入当作 HTML 执行。读取存储数据时进行基本结构校验，存储失败时显示提示。

## 文件结构

- `index.html`：页面结构与表单。
- `style.css`：配色、卡片布局及响应式样式。
- `app.js`：任务管理、筛选搜索、统计和本地持久化。

## Vibe Coding 开发过程

1. 向 AI 描述需求：创建可直接运行的学习任务管理工具。
2. 由 AI 生成页面、交互逻辑及说明文档。
3. 检查添加、完成、筛选、删除和持久化流程，并根据结果调整。

本项目由 AI 辅助开发。提交者应在提交前实际运行、理解核心逻辑，并根据自己的使用需求修改。

## 使用限制

数据保存在当前浏览器中，不会上传服务器，不支持跨设备同步。清除浏览器网站数据会清除任务；隐私模式或存储权限受限时可能无法持久保存。不同浏览器、访问地址或本地文件路径的数据可能互不共享。
